# Мануал по Neovim

> Открыть: `<leader>h` (leader = `Space`).  Поиск внутри: `/слово` и `n`/`N`, или `s` — нечёткий поиск по всему мануалу.  Закрыть: `q` или `Esc`.
> Прыгать по разделам: `]]` / `[[` (следующий / предыдущий заголовок).

Метки: **[ваш]** — кастомный хоткей из нашего конфига, **[плагин]** — из плагина, без метки — встроенный Vim.

Как учить: не читайте всё подряд. Берите по 3–5 команд на неделю из уровня,
на котором вы сейчас, и принудительно используйте их вместо мыши и стрелок.

---

# Уровень 0. Выжить

## Режимы
- `Esc` (или `Ctrl-[`) — вернуться в Normal. Это ваш «дом», в нём вы проводите 80% времени
- `i` — Insert (печатать перед курсором)
- `v` — Visual (выделение по символам)
- `V` — Visual line (выделение строк)
- `Ctrl-v` — Visual block (прямоугольное выделение)
- `:` — командная строка (Command mode)

## Сохранить и выйти
- `:w` — сохранить
- `:q` — закрыть окно
- `:wq` или `ZZ` — сохранить и закрыть
- `:q!` или `ZQ` — закрыть без сохранения
- `:qa` — закрыть всё
- `:wa` — сохранить все файлы
- `:e файл` — открыть файл
- `:e!` — перечитать файл, отбросив правки

## Отмена
- `u` — отменить
- `Ctrl-r` — повторить (redo)
- `U` — отменить все правки в строке

# Уровень 1. Перемещение

## Базовое
- `h` `j` `k` `l` — влево, вниз, вверх, вправо
- `w` — к началу следующего слова
- `b` — к началу предыдущего слова
- `e` — к концу слова
- `W` `B` `E` — то же, но слово = всё до пробела (включая знаки)
- `0` — начало строки
- `^` — первый непробельный символ строки
- `$` — конец строки
- `gg` — начало файла
- `G` — конец файла
- `42G` или `:42` — перейти на строку 42

## Прокрутка
- `Ctrl-d` — полэкрана вниз
- `Ctrl-u` — полэкрана вверх
- `Ctrl-f` / `Ctrl-b` — страница вниз / вверх
- `zz` — центрировать экран на курсоре
- `zt` / `zb` — курсор вверх / вниз экрана
- `H` `M` `L` — курсор на верх / середину / низ экрана

## Быстрые прыжки по строке
- `f<символ>` — прыгнуть на следующий символ в строке (`fa` — до `a`)
- `F<символ>` — то же назад
- `t<символ>` — прыгнуть ПЕРЕД символом
- `T<символ>` — то же назад
- `;` — повторить последний `f/t`
- `,` — повторить в обратную сторону

## Абзацы и скобки
- `}` / `{` — следующий / предыдущий пустой разрыв (абзац)
- `%` — перепрыгнуть на парную скобку `() [] {}`

## Счётчики
Почти любое движение принимает число: `5j` — 5 строк вниз, `3w` — 3 слова вперёд.
Включены относительные номера строк — смотрите число слева и прыгайте `7j`, `12k`.

# Уровень 2. Редактирование

## Войти в Insert по-разному
- `i` — перед курсором
- `a` — после курсора
- `I` — в начало строки
- `A` — в конец строки
- `o` — новая строка ниже
- `O` — новая строка выше

## Удалить / изменить
- `x` — удалить символ
- `dd` — удалить строку (она попадает в буфер обмена)
- `D` — удалить до конца строки
- `dw` — удалить слово
- `cw` — изменить слово (удалить и сразу в Insert)
- `cc` — изменить всю строку
- `C` — изменить до конца строки
- `r<символ>` — заменить один символ
- `s` — удалить символ и в Insert
- `J` — склеить следующую строку с текущей
- `~` — сменить регистр символа
- `>>` / `<<` — сдвиг строки вправо / влево
- `.` — **повторить последнее изменение** (очень мощная команда)

## Копировать и вставить
- `yy` — скопировать строку
- `yw` — скопировать слово
- `y$` — скопировать до конца строки
- `p` — вставить после курсора
- `P` — вставить перед курсором

Буфер обмена Vim связан с системным (`clipboard=unnamedplus`): скопировали в Vim — вставили в браузере и наоборот.

## Visual-режим
- `v` + движение — выделить, затем `d` (вырезать), `y` (копировать), `c` (изменить), `>` (сдвиг)
- `V` — выделить строки
- `Ctrl-v` — блок; затем `I` + текст + `Esc` вставит текст в начало каждой строки блока
- `gv` — повторно выделить предыдущее выделение
- `o` — прыгнуть к другому краю выделения

# Уровень 3. Грамматика Vim

Команда = **оператор** + **движение/объект**. Выучите операторы и объекты — комбинаций будет сотни.

## Операторы
- `d` — удалить
- `c` — изменить
- `y` — скопировать
- `>` `<` — сдвиг
- `gu` / `gU` — нижний / верхний регистр
- `=` — автоотступ

## Текстовые объекты
`i` = inside (внутри), `a` = around (вместе с обрамлением).

- `iw` / `aw` — слово
- `is` / `as` — предложение
- `ip` / `ap` — абзац
- `i"` / `a"` — внутри кавычек
- `i'` / `a'`
- `` i` `` / `` a` ``
- `i(` или `ib` / `a(` — внутри скобок
- `i{` или `iB` / `a{` — внутри фигурных скобок
- `i[` / `a[`
- `i<` / `a<`
- `it` / `at` — внутри HTML-тега (полезно для Angular-шаблонов)

## Примеры (запомнить как рецепты)
- `ciw` — заменить слово под курсором
- `ci"` — заменить текст в кавычках
- `di(` — удалить содержимое скобок
- `dap` — удалить абзац
- `yi{` — скопировать тело блока `{}`
- `cit` — заменить содержимое HTML-тега
- `vip` — выделить абзац
- `da"` — удалить строку вместе с кавычками
- `d3w` — удалить 3 слова
- `dt,` — удалить до запятой
- `df)` — удалить до закрывающей скобки включительно
- `c$` — то же, что `C`
- `gUiw` — слово в верхний регистр
- `>ip` — сдвинуть абзац

# Уровень 4. Поиск и замена

## Поиск
- `/текст` — искать вперёд, `Enter`
- `?текст` — искать назад
- `n` / `N` — следующее / предыдущее совпадение
- `*` — искать слово под курсором вперёд
- `#` — искать слово под курсором назад
- `:noh` — убрать подсветку поиска

Регистр: `ignorecase` + `smartcase` включены — маленькие буквы ищут без учёта регистра, если вписать заглавную — с учётом.

## Замена
- `:s/старое/новое/` — в текущей строке, первое совпадение
- `:s/старое/новое/g` — все в строке
- `:%s/старое/новое/g` — во всём файле
- `:%s/старое/новое/gc` — с подтверждением (`y` да, `n` нет, `a` все, `q` выход)
- `:'<,'>s/старое/новое/g` — только в выделении (нажмите `:` после выделения — часть подставится сама)
- `:%s/\<word\>/new/g` — слово целиком

## Макросы и повтор
- `q<буква>` — начать запись макроса (напр. `qa`)
- `q` — остановить запись
- `@a` — воспроизвести макрос
- `@@` — повторить последний макрос
- `5@a` — выполнить 5 раз
- `.` — повторить последнее изменение

Рецепт: записали макрос на одной строке, затем выделили строки и `:normal @a`.

## Метки
- `ma` — поставить метку `a` (строчные — внутри файла)
- `` `a `` — прыгнуть к точной позиции метки
- `'a` — прыгнуть к строке метки
- `Ctrl-o` — вернуться по списку прыжков назад
- `Ctrl-i` — вперёд
- `` `` `` — вернуться на прошлую позицию
- `gi` — вернуться в то место, где последний раз был Insert
- `g;` / `g,` — по списку изменений

## Регистры
- `"ayy` — скопировать строку в регистр `a`
- `"ap` — вставить из регистра `a`
- `"0p` — вставить последнее скопированное (`y`), даже если после этого что-то удаляли
- `:reg` — посмотреть все регистры
- `"_dd` — удалить без записи в буфер (в «чёрную дыру»)

# Уровень 5. Окна, буферы, табы

В Neovim три разных понятия:
- **Buffer** — открытый файл в памяти
- **Window** — окно, показывающее буфер (сплит)
- **Tab page** — набор окон (раскладка), а не «файл» как в VS Code

## Сплиты (окна)
- `:vsplit файл` / `:vs` — вертикальный сплит (рядом)
- `:split файл` / `:sp` — горизонтальный сплит (друг над другом)
- `Ctrl-w v` / `Ctrl-w s` — то же из Normal
- `Ctrl-w w` — по кругу
- `Ctrl-w q` — закрыть окно
- `Ctrl-w o` — оставить только текущее
- `Ctrl-w =` — выровнять размеры
- `Ctrl-w H/J/K/L` — переместить окно в сторону
- `Ctrl-w _` — максимизировать по высоте
- `Ctrl-w |` — максимизировать по ширине
- `Ctrl-w +` / `Ctrl-w -` — изменить высоту
- `Ctrl-w >` / `Ctrl-w <` — изменить ширину

Новые сплиты открываются справа и снизу (`splitright`, `splitbelow`).

## Переход между окнами **[ваш]**
`Ctrl-w` перехватывается iTerm, поэтому:
- `Ctrl-h` — окно слева
- `Ctrl-j` — окно снизу
- `Ctrl-k` — окно сверху
- `Ctrl-l` — окно справа

Работает и из терминала (панель Claude): выходит из режима ввода и переходит в соседнее окно. При входе в терминальное окно режим ввода включается автоматически.

## Буферы
- `:ls` — список буферов
- `:b имя` — перейти по части имени
- `:bn` / `:bp` — следующий / предыдущий
- `Ctrl-^` — переключиться на предыдущий буфер
- `:bd` — закрыть буфер
- `<leader>fb` **[ваш]** — список буферов в Telescope

## Tab pages
- `:tabnew файл` — новая вкладка
- `gt` / `gT` — следующая / предыдущая
- `3gt` — вкладка №3
- `:tabclose` — закрыть вкладку

## Вкладки сверху и сплиты **[ваш]**
Верхняя панель (bufferline) показывает открытые файлы как вкладки с номерами. Это буферы, а не tab pages:
файл из дерева (`<leader>e`) или Telescope открывается в текущем окне и появляется вкладкой.

| Клавиши | Действие |
|---|---|
| `H` / `L` | предыдущая / следующая вкладка |
| `<leader>1` … `<leader>8` | перейти на вкладку по номеру (`<leader>9` — последняя) |
| `<leader>bb` | выбрать вкладку буквой-подсказкой |
| `<leader>bd` | закрыть вкладку (окна/сплиты не ломаются) |
| `<leader>bo` | закрыть все остальные |
| `<leader>bp` | закрепить вкладку |
| `<leader>bh` / `<leader>bl` | сдвинуть вкладку влево / вправо |
| `<leader>sv` | вертикальный сплит (рядом) |
| `<leader>sh` | горизонтальный сплит (друг под другом) |
| `<leader>sx` | закрыть текущий сплит |
| `<leader>so` | оставить только текущее окно |
| `<leader>se` | выровнять размеры |
| `<leader>sm` | максимизировать окно |
| `<leader>s]` / `<leader>s[` | шире / уже |
| `<leader>s=` / `<leader>s-` | выше / ниже |
| `Ctrl-h/j/k/l` | переход между сплитами |

Рабочий процесс: `<leader>sv` → в новом окне открыть другой файл (`<leader>ff`) → править два файла рядом;
`H`/`L` переключает вкладку в *текущем* окне. Мышь тоже работает: клик по вкладке, крестик закрывает.
`H` и `L` теперь переключают вкладки; прежнее «верх/низ экрана» доступно через `<C-u>`/`<C-d>` или `gg`/`G`.
Русская раскладка работает: `Р`/`Д` = `H`/`L`, `<leader>ы…` = `<leader>s…`.

- `<leader>fs` — искать слово под курсором по проекту

- `Ctrl-x` — открыть в горизонтальном сплите
- `Ctrl-v` — открыть в вертикальном сплите
- `Ctrl-t` — открыть в новой вкладке
- `Ctrl-u` / `Ctrl-d` — прокрутка предпросмотра

## Дерево файлов (nvim-tree) **[ваш]**

Внутри дерева **[плагин]**:

- `Ctrl-v` — открыть в вертикальном сплите
- `Ctrl-x` — открыть в горизонтальном сплите
- `Ctrl-t` — открыть в новой вкладке
- `a` — создать файл (папка — с `/` в конце)
- `d` — удалить
- `r` — переименовать
- `x` — вырезать
- `c` — копировать
- `p` — вставить
- `y` — копировать имя, `Y` — относительный путь, `gy` — абсолютный путь
- `R` — обновить дерево
- `H` — показывать / скрывать dotfiles
- `W` — свернуть все папки
- `E` — развернуть все
- `-` — перейти в родительскую папку
- `g?` — справка по всем хоткеям дерева
- `q` — закрыть

# Уровень 7. Код: LSP, автодополнение, диагностика

LSP подключается автоматически к файлам (lua, ts, angular, eslint).

## Навигация по коду **[ваш]**
- `gd` — перейти к определению
- `gr` — найти все использования (references)
- `K` — документация / тип под курсором (hover)
- `<leader>rn` — переименовать символ во всём проекте
- `<leader>ca` — code action (быстрые исправления, импорты, рефакторинг)
- `<leader>d` — показать ошибку / диагностику под курсором
- `<leader>cf` — отформатировать файл (prettier)

## Встроенные диагностические хоткеи Neovim
- `]d` / `[d` — следующая / предыдущая диагностика
- `Ctrl-w d` — показать диагностику в float (через iTerm не сработает — используйте `<leader>d`)
- `grn` — переименовать (встроенный дубль)
- `gra` — code action (встроенный дубль)
- `grr` — references (встроенный дубль)
- `gri` — реализации
- `gO` — outline: список символов файла
- `Ctrl-s` в Insert — подсказка параметров функции

## Автодополнение (nvim-cmp) **[ваш]**
В режиме Insert:
- `Ctrl-Space` — вызвать подсказки вручную
- `Tab` / `Shift-Tab` — выбрать следующий / предыдущий пункт (также прыгает по полям сниппета)
- `Enter` — подтвердить выбранное
- `Ctrl-n` / `Ctrl-p` — следующий / предыдущий пункт
- `Ctrl-e` — закрыть окно подсказок
- `Ctrl-b` / `Ctrl-f` — прокрутка документации

Сниппеты: введите префикс (например, `for`), выберите пункт сниппета, `Tab` — прыжки по полям.

## Git (gitsigns) **[плагин]**
В поле слева видны отметки изменённых строк. Команды вызываются через `:Gitsigns`:
- `:Gitsigns preview_hunk` — показать, что изменилось в куске
- `:Gitsigns blame_line` — кто изменил строку
- `:Gitsigns reset_hunk` — откатить кусок
- `:Gitsigns stage_hunk` — добавить кусок в индекс
- `:Gitsigns next_hunk` / `prev_hunk` — к следующему / предыдущему изменению
- `:Gitsigns diffthis` — diff файла

Хоткеев у gitsigns в нашем конфиге нет. Добавьте, если будете пользоваться часто.

# Уровень 8. Claude (sidekick) **[ваш]**

- `<leader>aa` — открыть / скрыть панель Claude и перейти в неё
- `<leader>as` — выбрать, какого CLI-агента запустить
- `<leader>at` — отправить Claude «this» (текущая позиция / контекст)
- `<leader>af` — отправить Claude текущий файл
- `<leader>av` — отправить выделенный текст (в Visual)
- `<leader>ad` — отправить диагностику (ошибки)
- `<leader>ap` — выбор готового промпта

Панель Claude открывается **отдельной tmux-панелью** справа (режим `mux` в sidekick), а не окном nvim.
Так вывод идёт напрямую в tmux: нет лагов ввода и мусора на экране при выделении и скролле.
- Переключение между редактором и Claude — командами tmux (префикс `Ctrl-b` и стрелки, либо ваш bind).
- Работает только внутри tmux; вне tmux sidekick откроет обычное терминальное окно.
- Копирование мышью выполняет tmux/iTerm, а не nvim.
- Хоткеи `<leader>at/av/af/ad/ap` по-прежнему отправляют текст в эту панель.

Файлы, которые изменил Claude, подхватываются автоматически (`autoread`).

# Уровень 9. Продвинутое

## Работа с несколькими строками
- `:normal A;` в выделении (`:'<,'>normal A;`) — дописать `;` в конец каждой выделенной строки
- `Ctrl-v` + движение + `$` + `A` + текст + `Esc` — дописать текст в конец каждой строки блока
- `:g/шаблон/d` — удалить все строки с шаблоном
- `:g!/шаблон/d` или `:v/шаблон/d` — удалить все строки БЕЗ шаблона
- `:g/шаблон/normal @a` — выполнить макрос на всех совпавших строках
- `:sort` — отсортировать выделенные строки

## Свертки (folding)
- `zf` + объект — создать свертку (`zfap`)
- `za` — открыть / закрыть свертку
- `zR` — открыть все
- `zM` — закрыть все

## Quickfix (список результатов)
- `:copen` — открыть список
- `:cnext` / `:cprev` — следующий / предыдущий результат
- `:cdo s/старое/новое/g | update` — замена по всем результатам quickfix
- Рецепт массовой замены по проекту: Telescope live grep → `Ctrl-q` → `:cdo s/a/b/g | update`

## Команды ввода и вывода
- `:r файл` — вставить файл в текст
- `:r !команда` — вставить вывод shell-команды
- `:!команда` — выполнить shell-команду
- `:%!prettier --stdin-filepath x.ts` — прогнать буфер через внешнюю программу
- `:terminal` — открыть терминал в окне

## Insert-режим: полезное
- `Ctrl-w` — удалить слово перед курсором
- `Ctrl-u` — удалить до начала строки
- `Ctrl-o` — выполнить одну Normal-команду и вернуться в Insert
- `Ctrl-r 0` — вставить последнее скопированное
- `Ctrl-r "` — вставить из безымянного регистра
- `Ctrl-v` + код — вставить символ по коду

## Командная строка
- `q:` — окно истории команд
- `Ctrl-r Ctrl-w` в `:` — подставить слово под курсором
- `:help тема` — встроенная справка (`:h motion.txt`)
- `:h` + `Ctrl-d` — подсказки по подходящим темам

# Шпаргалка «что нажать, если…»

- Нужно выйти из чего угодно — `Esc`
- Не знаю, где я — `:ls`, `Ctrl-w w`
- Хочу найти файл — `Ctrl-p`
- Хочу найти текст по проекту — `Ctrl-g`
- Хочу перейти к определению — `gd`, вернуться — `Ctrl-o`
- Хочу переименовать переменную — `<leader>rn`
- Хочу отформатировать — `<leader>cf`
- Хочу спросить Claude — `<leader>aa`
- Хочу открыть два файла рядом — `<leader>sv`, затем `<leader>ff` (или `:vs файл`)
- Хочу сплит друг под другом — `<leader>sh`; закрыть сплит — `<leader>sx`
- Хочу переключить вкладку — `H` / `L` или `<leader>1…9`; закрыть — `<leader>bd`
- Хочу сделать коммит — `<leader>gg`; история файла — `<leader>gh`
- Русская раскладка включена, а команды не работают — перезапустить nvim (`langmap` и двойники подхватываются при старте)
- Хочу заменить слово — `ciw`, затем `.` на следующих
- Хочу заменить во всём файле — `:%s/a/b/gc`
- Забыл хоткей — `<leader>h`, затем `/слово`

# Русская раскладка **[ваш]**

Команды не зависят от раскладки: ничего переключать не нужно.

| Что | Как работает |
|---|---|
| Встроенные команды (`i`, `v`, `dd`, `ciw`, `w`, `b`…) | опция `langmap`: `ш`=`i`, `м`=`v`, `в`=`d` и т.д. (`lua/config/options.lua`) |
| Ваши маппинги (`<leader>e`, `<leader>gg`, `gd`…) | автоматические «двойники» с русскими буквами (`lua/config/langmap.lua`) |

Примеры: `<leader>у` = `<leader>e` (дерево), `<leader>аа` = `<leader>ff` (поиск файлов),
`<leader>фф` = `<leader>aa` (Claude), `<leader>пп` = `<leader>gg` (git).

Нюансы:
- Работает в Normal и Visual. В Insert и терминальном режиме печатается обычный текст.
- Двойники создаются для **любых** новых маппингов автоматически (в т.ч. из плагинов).
- Меняются только буквы; знаки препинания (`/`, `?`, `.`, `,`) с русской раскладки не переводятся.
- `Ctrl`-комбинации (`<C-h>`, `<C-p>`) и так не зависят от раскладки.

# Git прямо в nvim **[ваш]**

| Клавиши | Действие |
|---|---|
| `<leader>gg` | Neogit: статус. Внутри: `s` stage, `u` unstage, `x` discard, `c` commit, `?` помощь |
| `<leader>gc` | Коммит сразу |
| `<leader>gP` | Push |
| `<leader>gl` | Лог коммитов |
| `<leader>gd` | Diff рабочего дерева (diffview) |
| `<leader>gh` | История текущего файла |
| `<leader>gH` | История репозитория |
| `<leader>gq` | Закрыть diffview |

В окне статуса: `<Tab>` раскрывает diff файла, на строках/хунках можно делать `s`/`u` частично
(в Visual-режиме — выделенные строки). Сообщение коммита пишется в обычном буфере: `:wq` / `<C-c><C-c>` — подтвердить, `<C-c><C-k>` — отмена.

# План обучения (по неделям)

1. **Неделя 1.** Режимы, `hjkl`, `w b e`, `0 ^ $`, `gg G`, `u`, `Ctrl-r`, `:w`, `:q`. Уберите стрелки.
2. **Неделя 2.** `i a o O A I`, `dd yy p`, `x`, `cw`, `.`, `f t ; ,`, `Ctrl-d / Ctrl-u`.
3. **Неделя 3.** Текстовые объекты (`ciw`, `ci"`, `di(`, `dap`, `cit`), Visual-режим, `/ n N * #`.
4. **Неделя 4.** `:%s`, макросы `q @`, метки, `Ctrl-o / Ctrl-i`, регистры.
5. **Неделя 5.** Сплиты, `Ctrl-h/j/k/l`, Telescope, дерево файлов.
6. **Неделя 6.** LSP: `gd gr K <leader>rn <leader>ca`, автодополнение, git.
7. **Неделя 7+.** `:g`, `:cdo`, `Ctrl-v` блоки, folding, ваши собственные маппинги.

Золотое правило: если вы делаете одно и то же действие больше двух раз — найдите способ короче
(в этом мануале через `/` или в `:help`). Если команду забыли — не мышкой, а `<leader>h`.
